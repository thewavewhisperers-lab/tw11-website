# TW11 Website

The Wave Whisperers (TW11) — independent crypto-transaction recordkeeping guide.

The public website source is `index.html` in this repository. The private TW11 operations repository must remain private.

## Publishing through GitHub Pages

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose branch `main`, folder `/(root)`, then **Save**.
4. Wait for the Pages deployment confirmation, then open:
   https://thewavewhisperers-lab.github.io/tw11-website/

This URL is a prospective Pages address until deployment has been verified.
